# Sound Check

日本人が聞き分けにくい英語の音を、短い文章の中で練習できる3択リスニングクイズです。8つの発音カテゴリに各4種類、合計32種類の単語セットを収録しています。「もう一度」を押すと同じ3択を維持したまま、前回以外の2語から正解を再抽選し、選択肢も並び替わります。

## 使い方

`index.html` をブラウザで開くか、ローカルサーバーを起動してください。

```sh
python3 -m http.server 8000
```

クイズでは収録済みの自然なアメリカ英語音声を再生します。設定画面で音量を0〜100%に調整でき、選択した音量は次回も保持されます。音声ファイルを読み込めない場合のみ、ブラウザ標準の Speech Synthesis APIへ自動的に切り替わります。インストールやAPIキーは不要です。
